Using the Lab
Choose E0, E-F0, G1, G1-L or G2, configure the run, then launch. G1 is a deterministic symbolic QA2 control; G1-L trains identity/role binding on parsed QA2 events and reports validation and held-out evidence separately. Each run is saved under runs/experiment-lab/ with configuration, metadata and logs. E0 is isolated by design; continuous mode is available only for E-F0 and is a separate interference stress test.
For a fair comparison, match task, dimension, seed count, dataset splits, readout and epoch count. The dashboard reports metrics emitted by the actual runners.
