Registered dataset profiles
Select a profile on the experiment page. Profiles are defined in code/python/d2c/experiment_lab/dataset_profiles.json using repository-relative directories and split filenames. The Lab rejects paths outside the repository, checks the required splits, and records SHA-256 fingerprints for every available split with each run.
Protocol guide
Defaults follow each experiment’s documented protocol. Test is the locked evaluation split; validation is exploratory. G1 is a deterministic QA2 symbolic control. G1-L pilot results use validation and only the gated L2 stage opens test. G2 reports its internal matched E0/E-F0 task comparisons. Other runs are statistically compared only when the Lab confirms a matched E0/E-F0 configuration and matching dataset fingerprints.
Smoke mode is a small diagnostic slice, not benchmark evidence. Dataset identity and split hashes are part of each run’s configuration and manifest.
