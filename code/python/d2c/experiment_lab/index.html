Using the Lab
Choose E0, E-F0 or G1, configure the run, then launch. G1 is restricted to QA2 and is a deterministic symbolic control, not learned-model accuracy. Each run is saved under runs/experiment-lab/ with configuration, metadata and logs. E0 is isolated by design; continuous mode is available only for E-F0 and is a separate interference stress test.
For a fair comparison, match task, dimension, seed count, dataset splits, readout and epoch count. The dashboard reports metrics emitted by the actual runners.
